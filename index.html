Rakazo — personal instance

This is a private, self-hosted instance of Rakazo, an open-source AI assistant, run by an individual for their own use only.

It connects to the owner's own Google account (Gmail) through Google's OAuth so the owner's assistant can search, read, draft and organize the owner's email. It is not offered to the public and does not accept sign-ups.
